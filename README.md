# 🚀 LeadHunter AI — Парсер лидов и CRM-трекер (Instagram + Apify)

Веб-сервис для поиска клиентов под разработку сайтов и лендингов. 

Система находит профили в Instagram по любой нише и городу, анализирует ссылки в профилях, выявляет тех, у кого **нет сайта** (или есть только WhatsApp / Taplink / виджет записи), формирует удобную интерактивную CRM-таблицу, генерирует офферы через AI и скачивает базы в **Excel (.xlsx)**.

---

## ⚡️ Быстрый запуск на Windows (В 2 клика)

Если вы скачали архив с проектом или склонировали репозиторий:

1. **Шаг 1 (Разово)**: Дважды кликните по файлу **`install.bat`**
   * Скрипт сам проверит программы и автоматически установит все библиотеки для бэкенда и фронтенда (~1 минута).
2. **Шаг 2 (Для работы)**: Дважды кликните по файлу **`start.bat`**
   * Запустятся серверы и **браузер автоматически откроет сайт** по адресу `http://localhost:5173`.

> 💡 *Для последующих запусков файл `install.bat` больше нажимать не нужно — сразу запускайте `start.bat`!*

---

## 💻 Что должно быть установлено на компьютере

Перед первым запуском убедитесь, что на ПК установлены:
1. **[Python 3.10+](https://www.python.org/downloads/)** *(ВАЖНО: при установке обязательно поставьте галочку **"Add Python to PATH"**)*.
2. **[Node.js](https://nodejs.org/)** *(рекомендуется версия LTS)*.

---

## 🍎 Запуск на macOS и Linux (в терминале)

Если вы запускаете проект не на Windows:

```bash
# 1. Запуск Бэкенда (Терминал 1)
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 -m uvicorn main:app --reload --port 8000

# 2. Запуск Фронтенда (Терминал 2)
cd frontend
npm install
npm run dev
```

Сайт откроется по адресу: **http://localhost:5173**

## 🔑 Подключение Apify токена

Приложение поддерживает **2 режима**:

1. **Реальный парсинг через Apify**:
   * Нажмите кнопку **«Настройки Apify»** в правом верхнем углу сайта и вставьте ваш персональный API токен (из личного кабинета [Apify Console](https://console.apify.com/account/integrations)).
   * Токен сохранится в вашем браузере.
2. **Демо / Тестовый режим**:
   * Если токена нет, сервис работает в режиме демонстрации с генерацией реалистичных аккаунтов, чтобы вы могли бесплатно тестировать CRM-таблицы, фильтры и выгрузку в Excel без траты баланса Apify.

## 🎯 Основные функции системы

### 1. Главная страница (Поиск и Лид-трекер):
* **Поиск по ключевым словам**: ввод ниши и города (например: *«барбершоп москва»*, *«косметолог спб»*, *«ремонт квартир казань»*, *«дизайн интерьера»*).
* **Умные фильтры**:
  * 🔴 **Только БЕЗ сайта** — сразу оставляет только целевых клиентов, которым нужен сайт.
  * 🟡 **Только с WhatsApp** — бизнесы, принимающие заявки только в чат.
  * 🟣 **Мультиссылка (Taplink)** — аккаунты с сервисами мультиссылок.
  * **Все подряд**.
* **Интерактивная CRM-таблица**:
  * Чекбокс **«Писал?»** (переключение «Да/Нет» в один клик с мгновенным сохранением в базу).
  * Статусы ответа (*Не отправлено*, *Ожидает ответа*, *В диалоге*, *Думает*, *Отказ*, *Заказ сайта 🎉*).
  * Поле заметок по каждому клиенту.
  * Кнопка **«Столбцы»** — скрытие или включение любых колонок.
  * Удаление строк.
  * **Экспорт в Excel (.xlsx)** — скачивание красиво оформленной таблицы с авто-шириной столбцов и цветовой маркировкой.
* **AI Генератор офферов (LLM Mock)**:
  * Создание персонализированного коммерческого предложения под конкретного лида.
  * Выбор тональности (*Дружелюбный*, *Деловой B2B*, *Прямой*).
  * Копирование текста в буфер обмена в один клик и автоматическая отметка лида как «Писал».

### 2. База сессий (Архив):
* Каждый новый запуск парсинга создает **свою отдельную таблицу**.
* В архиве можно просмотреть статистику всех прошлых поисков, открыть любую сохраненную таблицу в трекере, продолжить работу со статусами или повторно скачать в Excel.

```text

├── install.bat          # 🛠 Установщик зависимостей в 1 клик (Windows)
├── start.bat            # 🚀 Запуск программы и открытие в браузере (Windows)

├── README.md            # Инструкция по использованию
│
├── backend/             # Бэкенд на Python FastAPI + SQLite
│   ├── database.py      # Подключение БД
│   ├── models.py        # Модели данных (Сессии, Лиды)
│   ├── schemas.py       # Схемы API
│   ├── main.py          # REST API эндпоинты

    │   ├── components/  # Таблица, поиск, модалки офферов и столбцов

    │   ├── services/    # API клиент
    │   └── App.jsx      # Главный модуль
    └── package.json     # Библиотеки JavaScript
```
